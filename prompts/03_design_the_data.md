Based on these requirements:

for a university internship platform MVP that:

- lets students browse internship placements
- lets students submit and track applications
- lets advisors approve or reject applications
- lets students submit progress updates
- tracks the core entities Placement, Application, Approval, and ProgressUpdate

Identify the minimum data model required for the MVP.

For each entity provide:

- Entity name
- Important fields
- Relationships
- Who can create/read/update/delete it

Do not over-design.

Also identify:

1. Data that should NOT be stored
2. Sensitive data
3. Potential duplicate or inconsistent data
4. Important database constraints
